# Click what you want

Click the value you want to collect. Studio shows the ways to find it again on the next visit, with how many things each one matches:

- the suggested one is the most reliable;
- an id that changes on every visit is never used;
- you can type your own.

Click a **second, similar** value (the next product's name, say) and Studio collects the **whole list**.

When a way to find it matches several things, you choose: only the first, or all of them as a list.

Then press **Add to recipe**.
