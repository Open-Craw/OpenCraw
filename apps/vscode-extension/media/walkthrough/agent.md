# Let an AI agent use OpenCraw

OpenCraw ships an MCP server: the same tools you have (look at a page or a file, check a recipe, run a crawl) for an AI agent.

- **VS Code agent mode**: nothing to do. Open the chat in agent mode, look at its tools, and OpenCraw is there.
- **Claude Code, Cursor and other agents**: run **OpenCraw: Copy the MCP configuration for another agent**, pick your agent and paste what it copies.

An agent can write and check recipes with you, and run them; you can always open what it made in Studio and change it by clicking.
