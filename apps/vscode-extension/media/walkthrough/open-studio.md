# Open Studio

Studio is where you build recipes by clicking. It starts on your computer, for this workspace, and opens in your browser: nothing is sent anywhere.

Use **OpenCraw: Open Studio** from the command palette, or right-click any file or folder and choose **Open on OpenCraw**. A PDF, a spreadsheet, a Word file, a JSON or Markdown file starts a recipe straight away.

The first time can take a few seconds while the server starts.
