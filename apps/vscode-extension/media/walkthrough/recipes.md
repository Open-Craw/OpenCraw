# Run it from the editor

The **OpenCraw** view in the sidebar lists your recipes, grouped by the output they fill.

- **Run** on an input recipe runs just that one.
- **Run** on an output recipe runs every input that feeds it.
- When the crawl is over you choose where to save the result, and its format is the file's extension: Excel (`.xlsx`), CSV, a web page (`.html`), PDF, JSON, JSON Lines or YAML.
- **Open in Studio** opens the recipe to change it.
