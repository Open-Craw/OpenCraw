# Run a sample

Press **Run sample**. The records appear in a table at the bottom, and the **Trace** tab tells you what the crawl did, step by step.

If a value is missing or wrong, **Why?** explains which step produced it and what it saw.

When it looks right, the recipe is already saved in your folder as two files:

- an **input recipe** (`.ocw-in.json`): where to read, and what to take;
- an **output recipe** (`.ocw-out.json`): the shape of the result. Different inputs can fill the same output, so different sources give you the same kind of data.
